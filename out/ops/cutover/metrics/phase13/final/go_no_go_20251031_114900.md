## ROOT CAUSE ANALYSIS

### Primary Issue: Route Registration Failure

**Evidence:**
1. Routes ARE defined in source code:
   - `apps/api/src/routes/domain/picks-insert.ts` ✅ exists
   - `apps/api/src/routes/domain/picks.ts` ✅ exists
   - `apps/api/src/api-server.ts` lines 77-78 ✅ registers routes

2. Routes ARE imported in api-server.ts:
   ```typescript
   import domainPicksRouter from './routes/domain/picks';
   import { picksInsertRouter } from './routes/domain/picks-insert';
   app.use('/api/domain/picks', domainPicksRouter);
   app.use('/api/domain/picks', picksInsertRouter);
   ```

3. Routes NOT served by running container:
   - Container running: `tsx src/index.ts` (development mode)
   - Health endpoint works: `/api/health` ✅
   - Smart form works: `/api/smart-form/process` ✅
   - Domain picks routes: 404 ❌

**Hypothesis:**
- TypeScript compilation errors in route files preventing module loading
- Confirmed: `tsc --noEmit` shows errors in `picks-insert.ts`:
  - `error TS1192: Module 'dotenv' has no default export`
  - `error TS1259: Module 'express' can only be default-imported using esModuleInterop flag`
  - Additional glob/minimatch type errors

**Secondary Issue: Schema Mismatch**
- Outbox publisher error: `column pick_publish.next_attempt_at does not exist`
- Should be: `next_retry_at` (per migration 20251102_pick_publish_outbox.sql)
