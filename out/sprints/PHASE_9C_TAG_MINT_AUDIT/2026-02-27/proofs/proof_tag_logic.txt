Pattern: ^(PHASE|SPRINT|GOVERNANCE)[A-Z0-9._-]+$

Breakdown:
  ^ - Start of string
  (PHASE|SPRINT|GOVERNANCE) - Must start with one of these
  [A-Z0-9._-]+ - Followed by uppercase letters, numbers, dots, underscores, hyphens
  $ - End of string
