# Unit Talk Discord Bot - Quick Start Guide

## 🚀 **Get Started in 5 Minutes**

Welcome to Unit Talk! This guide will help you get up and running quickly with
our comprehensive sports betting Discord bot.

---

## 📋 **Step 1: Join the Server**

1. **Click the invite link** provided by your friend or community
2. **Accept the invitation** to join the Unit Talk Discord server
3. **Read the welcome message** and server rules
4. **Introduce yourself** in the #general channel

---

## 🎯 **Step 2: Your First Commands**

### **Check Your Status**

```
/help
```

This shows you all available commands based on your current tier.

### **View Your Stats**

```
/stats
```

See your current performance and activity.

### **Submit Your First Pick**

```
/pick sport:NFL selection:Chiefs -3.5 odds:-110 units:2 confidence:7
```

Replace with your actual pick details.

## 🔧 **Troubleshooting**

### **Command Not Working?**

1. Check your permissions with `/help`
2. Verify you're in the right channel
3. Use `/support technical` for help

### **Can't Access Features?**

1. Check your tier with `/trial-status`
2. Upgrade with `/vip-info`
3. Contact support with `/support`

### **Bot Not Responding?**

1. Try `/ping` to check status
2. Check server announcements
3. Contact support if issues persist
