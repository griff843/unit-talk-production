# DX-OPS Daily Workflow Shortcuts

Quick reference for daily Unit Talk development operations.

## pnpm Commands (Cross-Platform)

These commands work on both Windows (PowerShell) and Unix (bash):

```bash
# Health check - verify all services are running
pnpm ops:health

# Bootstrap - full setup from scratch
pnpm ops:bootstrap

# Restart - clean restart of all services
pnpm ops:restart

# Restart specific services only
pnpm ops:restart -- --services api,smart-form

# Restart without waiting for health
pnpm ops:restart -- --no-wait

# DANGEROUS: Wipe volumes and restart (loses all data)
pnpm ops:restart -- --wipe
```

## Docker Compose Commands

```bash
# Start all services
docker compose up -d

# Stop all services
docker compose down

# View running containers
docker compose ps

# View logs (all services)
docker compose logs -f

# View logs (specific service)
docker compose logs -f api

# Restart a specific service
docker compose restart api

# Rebuild a service
docker compose build api
docker compose up -d api
```

## PowerShell Aliases (Optional)

After running `.\tools\profile\install-profile.ps1 -Apply`:

| Alias | Command | Description |
|-------|---------|-------------|
| `ut-cd` | `Set-Location $PROJECT_ROOT` | Navigate to project |
| `ut-up` | `docker compose up -d` | Start containers |
| `ut-down` | `docker compose down` | Stop containers |
| `ut-logs [svc]` | `docker compose logs -f [svc]` | View logs |
| `ut-ps` | `docker compose ps` | List containers |
| `ut-health` | `pnpm ops:health` | Run health check |
| `ut-bootstrap` | `pnpm ops:bootstrap` | Full bootstrap |
| `ut-restart` | `pnpm ops:restart` | Clean restart |
| `ut-proof [name]` | View proof file | Show proof artifacts |

### Alias Examples

```powershell
# Start containers
ut-up

# View API logs
ut-logs api

# Quick health check
ut-health

# Restart with wipe
ut-restart -Wipe

# View today's bootstrap proof
ut-proof bootstrap
```

## Daily Development Workflow

### Morning Startup

```bash
# 1. Verify Docker Desktop is running (Windows)
# 2. Quick health check
pnpm ops:health

# 3. If unhealthy, restart
pnpm ops:restart

# 4. Open services
start http://localhost:3004  # Command Center
start http://localhost:3002  # Smart Form
```

### After Code Changes

```bash
# Rebuild and restart changed service
docker compose build api
docker compose up -d api

# Or for full restart
pnpm ops:restart
```

### Before Leaving

```bash
# Stop all services to free resources
docker compose down

# Or leave running for background processing
# (services will auto-restart if Docker restarts)
```

### After Git Pull

```bash
# Full bootstrap to pick up new dependencies/migrations
pnpm ops:bootstrap
```

## Proof Artifacts

All ops commands generate proof files in:
```
out/dx-ops-pack/<date>/
```

| File | Generated By | Contains |
|------|--------------|----------|
| `proof_health.txt` | `ops:health` | Health check results |
| `proof_bootstrap_windows.txt` | `ops:bootstrap` (Windows) | Full bootstrap log |
| `proof_bootstrap.txt` | `ops:bootstrap` (Unix) | Full bootstrap log |
| `proof_restart.txt` | `ops:restart` | Restart log |
| `proof_container_status.txt` | `ops:bootstrap` | Container status |
| `logs_<service>.txt` | `ops:health` (on failure) | Service logs |

View proofs:
```bash
# Windows PowerShell
Get-Content out\dx-ops-pack\2026-02-14\proof_health.txt

# Unix
cat out/dx-ops-pack/2026-02-14/proof_health.txt

# Using ut-proof alias (PowerShell)
ut-proof health
```

## Troubleshooting Quick Reference

| Symptom | Quick Fix |
|---------|-----------|
| Docker not running | Start Docker Desktop |
| Service unhealthy | `pnpm ops:restart` |
| Database issues | `pnpm ops:restart -- --wipe` |
| Port conflict | Find/kill process on port, then restart |
| Node modules broken | `rm -rf node_modules && pnpm install` |
| Build errors | `docker compose build --no-cache <service>` |

For detailed troubleshooting, see [DEV_ENV_WINDOWS.md](./DEV_ENV_WINDOWS.md).
