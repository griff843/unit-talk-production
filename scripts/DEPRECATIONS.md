# Script Deprecations

The following ad-hoc scripts are legacy and will be removed or consolidated:

- apps/command-center/manual-verification.js
- apps/command-center/test-bypass.js
- apps/smart-form/direct-migration.js

Banner to prepend at the top of deprecated scripts:

```
/**
 * DEPRECATION NOTICE
 * This script is legacy and will be removed or consolidated.
 * Prefer using scripts in scripts/ops or documented npm scripts in the repo root package.json.
 */
```

Please open an issue if you rely on any deprecated script so we can provide a supported path.
