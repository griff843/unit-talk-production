# DISCORD_EMBED_CONTRACT.md

**Version:** 2.0.0 **Date:** 2026-02-11 **Status:** LOCKED **Updated:**
DISCORD-EMBED-FINAL-POLISH

---

## Overview

This contract defines the required fields, formatting, and structure for Discord
pick embeds generated by the Unit Talk platform. All embeds MUST conform to this
contract.

---

## Required Fields

All Discord pick embeds MUST include the following fields:

| Field                      | Type           | Description                       | Example                                       |
| -------------------------- | -------------- | --------------------------------- | --------------------------------------------- |
| `title`                    | string         | Pick direction with line          | "Over 25.5"                                   |
| `odds_american`            | string         | American odds with sign           | "-110", "+150"                                |
| `market_label`             | string         | Player/Team + Stat Type           | "LeBron James – Points OU"                    |
| `context_line`             | string         | Sport + Game Time                 | "NBA • (Feb 3, 2026)"                         |
| `units`                    | string         | Unit stake                        | "1U", "2U"                                    |
| `confidence`               | number \| null | Confidence rating (0-10)          | 8, null                                       |
| `units_confidence_display` | string         | Combined units + confidence       | "2U • 8/10", "1U"                             |
| `thumbnail_url`            | string         | Image URL (headshot/logo/default) | "https://cdn.nba.com/..."                     |
| `pick_id`                  | string         | UUID                              | "37ce4a3c-a224-4c2c-..."                      |
| `market_type`              | string         | Market classification             | "player_prop", "spread", "moneyline", "total" |
| `sport`                    | string         | Sport code                        | "NBA", "NFL", "MLB", "NHL"                    |

## Thumbnail Rules

### Priority Chain (Player Props)

1. `players.headshot_url` from database
2. Generated headshot URL (ESPN/NBA/MLB CDN)
3. Team logo from `teams.logo_url`
4. UNIT_TALK_DEFAULT_THUMBNAIL

### Priority Chain (Team Picks - Moneyline/Spread)

1. `teams.logo_url` from database
2. Generated logo URL (ESPN CDN)
3. UNIT_TALK_DEFAULT_THUMBNAIL

### Priority Chain (Game Totals) ✨ NEW v2.0.0

1. **League logo** (e.g.,
   `https://a.espncdn.com/combiner/i?img=/i/teamlogos/leagues/500/nba.png`)
2. UNIT_TALK_DEFAULT_THUMBNAIL

> **Rationale**: Game totals (Over/Under on total points) don't represent a
> specific team, so league logo is more appropriate.

### Never Return Null

The thumbnail_url MUST always have a value. If all priorities fail, use the
default thumbnail.

## Title Formatting Rules

### Player Props

```
{Direction} {Line}
```

Example: "Over 25.5", "Under 8.5"

### Spreads

```
{Team} {Spread}
```

Example: "Lakers -3.5"

### Moneylines

```
{Team} ML
```

Example: "Lakers ML"

### Totals

```
{Direction} {Total}
```

Example: "Over 220.5"

---

## Market Label Formatting

### Player Props

```
{PlayerName} – {StatType} {Market}
```

Example: "LeBron James – Points OU"

### Team Props

```
{Team} – {StatType}
```

Example: "Lakers – Total Points"

## Forbidden Fields

The following fields MUST NOT appear in embeds:

| Field                 | Reason                            |
| --------------------- | --------------------------------- |
| `direction: "N/A"`    | Direction should be in title      |
| `stat_type` (raw)     | Must be formatted in market_label |
| `player: "Player"`    | Must use actual player name       |
| `thumbnail_url: null` | Must always have fallback         |

---

## Context Line Format

```
{Sport} • {Matchup} • ({FormattedDateTime})
```

### Date/Time Formatting

- Include month, day, year, and time (when available)
- Example: "Feb 3, 2026, 7:00 pm"

### Manual Entry Time Handling ✨ NEW v2.0.0

- If game time comes from manual entry (date-only format), **DO NOT** show a
  fake time
- **CORRECT**: "Feb 3, 2026"
- **WRONG**: "Feb 3, 2026, 12:00 am"

> **Rationale**: Manual entries may only have date without time. Showing "12:00
> am" is misleading.

---

## Confidence Display ✨ NEW v2.0.0

### Fields

- `confidence`: Integer 0-10 (from Smart Form) or null
- `units_confidence_display`: Combined display string

### Format Rules

- **With confidence**: `"{units}U • {confidence}/10"` → "2U • 8/10"
- **Without confidence**: `"{units}U"` → "1U"

### Examples

| units | confidence | units_confidence_display |
| ----- | ---------- | ------------------------ |
| 2     | 8          | "2U • 8/10"              |
| 1.5   | 7          | "1.5U • 7/10"            |
| 1     | null       | "1U"                     |
| 1     | 0          | "1U"                     |

---

## Validation Rules

1. **title**: Non-empty string
2. **odds_american**: Starts with + or -, followed by digits
3. **market_label**: Contains "–" separator
4. **context_line**: Contains "•" separator
5. **units**: Ends with "U"
6. **thumbnail_url**: Valid URL starting with https://
7. **pick_id**: Valid UUID format
8. **sport**: One of: NBA, NFL, MLB, NHL, NCAAB, NCAAF, WNBA

---

## CI Enforcement

A CI gate (`embed-contract-gate.yml`) validates:

1. All required fields are present
2. No forbidden patterns detected
3. Title is properly formatted
4. Thumbnail URL is not null

## Parlay Ticket Embed v1 ✨ NEW v2.1.0

### PARLAY-DISCORD-GROUPING-001

Parlay tickets (2+ legs) MUST post as a **single Discord message** containing
all legs.

### Parlay Embed Structure

| Field                 | Type   | Description                     | Example           |
| --------------------- | ------ | ------------------------------- | ----------------- |
| `title`               | string | Parlay indicator with leg count | "🎲 2-Leg Parlay" |
| `description`         | string | All legs formatted              | See below         |
| `total_odds_american` | string | Combined parlay odds            | "+273"            |
| `total_units`         | string | Total units for ticket          | "2U"              |
| `tier`                | string | Ticket tier                     | "C-Tier"          |
| `thumbnail_url`       | string | League logo or default          | See rules below   |

### Legs Description Format

Each leg displayed as:

```
**Leg {N}:** {Title} ({Odds}) • {Matchup}
```

Example:

```
**Leg 1:** Lakers -3.5 (-110) • Heat @ Lakers
**Leg 2:** Over 220.5 (-105) • Celtics @ Bulls
```

### Leg Display Limits

- Show first 6 legs in full
- If more than 6 legs: add "_+N more leg(s)_"

### Parlay Thumbnail Rules

1. If ALL legs share same sport → Use league logo
2. Otherwise → UNIT_TALK_DEFAULT_THUMBNAIL

### Idempotency Rules

- ALL legs in a parlay MUST share the same `discord_message_id`
- If ANY leg is already posted, the ENTIRE ticket is skipped
- Re-runs MUST NOT create duplicate messages

### Database Columns

All legs in a parlay ticket store:

- `posted_to_discord: true` (set atomically on all legs)
- `meta.discord_receipt.message_id` (same value across all legs)
- `meta.discord_receipt.ticket_type: "parlay"`
- `meta.discord_receipt.leg_count` (total legs)

### Single Pick Behavior (Unchanged)

- 1 pick = 1 Discord message
- Existing embed format preserved
- No changes to single pick handling
